【1) A3 与精度系统对齐 —— 已完成代码改动】
现状：A3 原先用"硬件最高精度等级 ≥ 算子要求等级"的等级近似判断，且只看单一精度，
和精度系统的"类别 + 数据精度 + 执行精度 三维列表包含"语义不一致。
改动（core/validator.py）：A3 现在按硬件 type 查精度系统的能力表 HARDWARE_CAPABILITY，
对每个算子做两项精确检查——
  a) 类别能力：算子类别（LINEAR/NONLINEAR，按 op_type 判定）必须在硬件 categories 里；
  b) 执行精度能力：算子要求的执行精度必须精确在硬件 execution 列表里。
仅当硬件类型不在能力表（自定义类型）时，才回退到旧的等级判断。
这样"校验结果 = 运行时 HardwareUnit.can_execute 结果"，两者不再打架。

样例（对比如下）：
  - GPU + LayerNorm(FP32)：通过 —— GPU 类别=NONLINEAR全支持、execution 含 FP32。
  - DRAM-PIM + LayerNorm：A3 拒 —— DRAM-PIM 只能算 LINEAR 类，不能跑归一化。
  - GPU + GEMM(INT8)：通过 —— GPU execution 含 INT8。
  - GPU + KV_Cache_Update(INT4)：A3 拒 —— GPU execution 不含 INT4。
  （这些与运行时可执行结果完全一致。）

【2) 各规则的"人话+例子"说明（方便你看懂）】
